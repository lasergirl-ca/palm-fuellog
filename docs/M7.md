# M7: IR and Bluetooth

Built 2026-10-24 while Zoe was out; unverified on the device (and needs a second Palm).

## Sending (US-27 to US-29; `src/beam.c`, `exp2` section)

- The Export form's Format row gained **Log**, and **Send to: Other Palm** sends over the
  Exchange Manager with the "?_send:" chooser, so the T|X offers IR or Bluetooth. Log sends a
  .fuel records bundle: "FUEL", schema version, kind, a record count, then each record as
  database number, length and the packed bytes (vehicles, programmes, service types, visits,
  fills; one vehicle's when a vehicle is chosen). CSV, XLSX or PDF go inside a file envelope
  (kind 2, the file name and format, then the bytes) straight from the same writers through
  an OutStream whose write is ExgSend; the XLSX writer runs in its data-descriptor mode since
  the socket cannot seek.
- FuelLog registers the .fuel extension and the application/x-fuellog type at launch.

## Receiving

- `ReceiveBeam` in main.c handles sysAppLaunchCmdExgReceiveData with system traps only, since
  the app may not be running (no globals, no jump table): a file envelope is written to the
  card, PDFs into Export/ and CSV or XLSX into Import/ so Choose a file finds them; a records
  bundle is gathered in memory and stored as one record of an inbox database
  (FuelInbox-ZFlg). When the app is running (sub-call), the inbox is processed at once.
- `BeamProcessInbox` runs at every launch: for each bundle it asks Merge, Replace or Discard.
  Merge maps vehicles and programmes by name to existing ids (new ones get free ids), service
  types by vehicle and name, remaps visit masks and fill points, and skips fills and visits
  already here (same vehicle, date and odometer). Replace clears the five databases first and
  keeps the bundle's ids. A bundle from a newer schema is refused.

## Check with two Palms
1. Export, Log, Other Palm, Export: the chooser offers Beam and Bluetooth; the other Palm asks
   to accept, then FuelLog there asks Merge or Replace.
2. Export, CSV, Other Palm: the file lands in Import/ on the other card and shows in Choose a
   file.
